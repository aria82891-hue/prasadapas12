# prasadapas12
aplikasi web  untuk mengerjakan sku penggalang 

Saat ujian SKU Rakit atau Terap berlangsung, peserta harus mengumpulkan jawaban sebelum kembali ke dashboard. Tombol kembali di dalam ujian telah dihapus, dan navigasi kembali melalui riwayat browser tetap menampilkan ujian selama sesi aktif.

Berpindah tab atau menyembunyikan halaman menghapus jawaban SKU yang sedang dikerjakan dan mengulangnya dari awal. Saat peserta kembali, pesan “jangan kayak gitu lagi yaa” ditampilkan. Memuat ulang atau membuka kembali sesi ujian yang belum selesai juga mengulang SKU tersebut. Hasil SKU lain yang sudah selesai tidak berubah.

Pendeteksian menggunakan perubahan visibilitas halaman, bukan hilangnya fokus, sehingga dialog PIN atau konfirmasi pengumpulan tidak dianggap sebagai perpindahan tab. Browser tetap mengizinkan peserta menutup tab atau meninggalkan situs; penguncian berlaku pada navigasi aplikasi dan tombol kembali selama ujian aktif.
